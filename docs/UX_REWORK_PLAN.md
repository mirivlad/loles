# План UX и функциональной переработки LoLeS

Дата начала: 20.11.2026. Приоритет — рабочие сценарии учебного центра, не декоративный редизайн.

## Правила разработки и проверки

1. Разработка по пунктам, отдельный коммит на функциональный блок.
2. После каждого пункта: автоматические тесты и проверка интерфейса в браузере с ролями **менеджер** и **учащийся**. Для административного раздела студент не должен видеть органы управления.
3. Все массовые списки: серверная пагинация, поиск по мере ввода, фильтры в URL. Не загружать тысячи записей в выпадающие списки.
4. Браузеры после QA закрывать; не оставлять на сервере фоновые процессы.
5. Работать с тестовыми данными, не уничтожать учётные записи и не публиковать секреты. Существующих курсов в промышленной эксплуатации нет; совместимость старого редактора не приоритет.
6. Фиксировать статус, коммит, CI и результаты осмотра в этом файле. Без реальной проверки пункт не закрывать.
7. Публикация latest — только после успешного CI; для браузерного тестирования предпочтителен изолированный стенд.

## Этап I — корректность обучения и явные дефекты

- [x] **UX-01. Даты назначения.** Доступ только после начала и до окончания включительно, проверка в каталоге учащегося, на уроке и при скачивании материалов.
  **Приёмка:** будущие и истёкшие назначения не дают доступ, текущие работают, границы дат покрыты тестами.
- [x] **UX-02. Заявки.** Выбор «Ожидает» сохраняет заявку без назначения даже администратором. Только явное одобрение создаёт назначения.
  **Приёмка:** обе ветки проверены; менеджеру понятен эффект кнопки сохранения.
- [x] **UX-03. Неработающие ссылки.** Быстрые действия действительно открывают нужные формы. «Отчёты» должны вести в рабочий раздел, либо не быть ложной ссылкой.
  **Приёмка:** все такие кнопки пройдены браузером, нет пустых переходов.
- [ ] **UX-04. Понятные подписи.** Обозначения в таблицах, роли на русском, технический slug скрыт от менеджера, единая терминология, понятные действия.
  **Приёмка:** менеджер может понять таблицы без расшифровок.

## Этап II — полноценная работа с группами

- [ ] **UX-05. Состояния групп.** «Запланирована», «Обучается», «Завершена», «Архив», даты начала и завершения, сохранение истории.
  **Приёмка:** завершённая группа остаётся доступной для ведомости и не мешает активным.
- [ ] **UX-06. Каталог для 1500+ групп.** Поиск по имени, предприятию, фильтры состояния и архива, пагинация, счётчик результатов.
  **Приёмка:** на синтетических тысячах записей поиск работает без загрузки всех вариантов.
- [ ] **UX-07. Массовые селекторы.** Выбор пользователя, группы, предприятия и курса через серверный typeahead с контролем прав.
  **Приёмка:** менеджер находит по части названия, учащемуся административный поиск недоступен.

## Этап III — управление обучением

- [ ] **UX-08. Назначения.** Отображать получателей, период, состояние, количество учеников и результаты. Разные назначения не смешивать только по дате.
  **Приёмка:** видно кому, когда и что нужно завершить.
- [ ] **UX-09. Отчёты.** Рабочие фильтры по предприятию, группе, курсу, периоду и статусу и выгрузки ведомостей.
  **Приёмка:** менеджер находит завершённый поток и получает сведения.
- [ ] **UX-10. Управленческий рабочий стол.** Ближайшие окончания, заявки, незавершённые назначения и рабочие быстрые действия.
  **Приёмка:** понятна ближайшая работа.
- [ ] **UX-11. Единые списки и формы.** Единый стиль фильтров, сброса и кнопок; создание теста непосредственно из каталога.
  **Приёмка:** сценарии повторяемы, нет лишних переходов.

## Этап IV — редактор и прохождение курса

- [ ] **UX-12. Редактор.** Авточерновик, защита от потери изменений, удобная загрузка PDF/изображений, восстановление позиции вставки.
  **Приёмка:** менеджер не теряет текст, студент видит вложения.
- [ ] **UX-13. Читатель курса.** Содержание, отдельный урок, далее/назад, H5P/SCORM, промежуточные и итоговые тесты; заглушки честно помечены.
  **Приёмка:** последовательность пройдена с обеими ролями без 500 и тупиков.
- [ ] **UX-14. Адаптивность.** Проверка десктопа, планшета, мобильной ширины, длинных названий, клавиатуры, подписей кнопок.
  **Приёмка:** нет обрезанных обязательных действий и скролла всей страницы по горизонтали.
